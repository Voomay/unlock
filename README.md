# Unlock Cape Town Tours — Official Website (`www.unlockcapetowntours.co.za`)

Official responsive website for **Unlock Cape Town Tours** featuring **Louis Hendry** (Registered Western Cape Tourist Guide: **WC 16800**).

## Project Structure
- `index.html` — Complete landing page, filterable tour showcase, guide profile, interactive custom quote builder, testimonials, and FAQ.
- `styles.css` — Custom styling inspired by the Unlock Cape Town Tours logo (Deep Fynbos Olive, Atlantic Ocean Teal, King Protea Crimson, Golden Padlock Brass, and Warm Cape Sandstone Cream).
- `script.js` — Interactive stop-by-stop tour itinerary modals, category filtering, pre-filled WhatsApp & Email quote builders, and one-click vCard (`.vcf`) contact download.
- `assets/logo.png` — Extracted high-resolution circular logo badge with transparent background.
- `assets/business-card.jpg` — Official Unlock Cape Town Tours digital business card.
